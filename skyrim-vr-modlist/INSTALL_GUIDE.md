# Руководство по установке Skyrim VR Core 2026

Фазы, инструменты, пути и проверки. Читается вместе с `manifest.yaml` (что ставить) и `CONFLICTS.md` (порядок и запреты).

**Надёжность фактов.** Раздел «Файлы профиля MO2» и устройство Root Builder проверены по исходному коду MO2 2.5.2 и документации Root Builder. Настройки Engine Fixes VR 7.x — по `SETTINGS.md` автора. Остальное взято из README на GitHub и сниппетов поисковой выдачи; такие места помечены **(проверить)**. Страницы Nexus при составлении были недоступны, поэтому названия опций установщиков (FOMOD) агент читает сам у реальных установщиков.

## 0. Подготовка компьютера

1. Установите Microsoft Visual C++ Redistributable (x64, 2015–2022) и .NET 8 Runtime; для Synthesis нужен .NET SDK, не только Runtime.
2. Skyrim VR — в **отдельную библиотеку Steam** (например `D:\SteamLibrary`), не в Program Files. Язык игры — English (для русской игры см. раздел «Русский язык»).
3. **Один раз запустите игру из Steam** до главного меню и выйдите: иначе в `Documents\My Games\Skyrim VR` не появятся INI, и MO2 не создаст профиль.
4. SteamVR: разрешение рендера **100% и глобально, и для игры**. Суперсэмплинг поверх апскейла Open Shaders съедает кадры.
5. Отключите оверлеи (Discord и другие) и игровой режим Windows: они мешают SKSEVR.
6. Видеопамять: 2K по умолчанию, 4K — только для близких предметов.

## 1. MO2 и профиль

1. Распакуйте MO2 2.5.2 в отдельную папку вне Steam, Program Files и папки игры. Запустите `ModOrganizer.exe` → **Create a new instance → Portable**, игра **Skyrim VR**, папка с `SkyrimVR.exe`. Портативным экземпляр считается, если рядом с `ModOrganizer.exe` лежит `ModOrganizer.ini`.
2. Создайте профиль (`PROFILE`), включите **Use profile-specific Game INI Files** и **Use profile-specific Save Games**. MO2 управляет ровно двумя INI: `skyrimvr.ini` и `skyrimprefs.ini`. Сохранения идут в `profiles\<профиль>\saves` (в `skyrimvr.ini` MO2 пишет `sLocalSavePath=__MO_Saves\` и `bUseMyGamesDirectory=1` — эти ключи не удалять).
3. Установите **Root Builder** (Kezyma, #31720): папка `rootbuilder` в `<MO2>\plugins\`, перезапуск MO2.

### Файлы профиля MO2 — правила для прямой правки (проверено по коду MO2)

Править можно только при **закрытом MO2** и после копии папки `profiles\<профиль>`. После правки откройте MO2 один раз и убедитесь, что порядок и галочки верны, и только потом запускайте игру.

| Файл | Формат и правила |
|---|---|
| `modlist.txt` | Первая строка — комментарий `# This file was automatically generated by Mod Organizer.`, UTF-8, CRLF. Строки: `+Имя` (включён), `-Имя` (выключен). **Верхняя строка файла = наивысший приоритет (побеждает при конфликте) = нижний мод в левой панели MO2.** Нижняя строка — самый низкий приоритет, верх панели. Файл — перевёрнутая копия панели. Агент пишет список от самого высокого приоритета к самому низкому, и порядок «сверху вниз как в панели» из манифеста нужно при записи **перевернуть**. Имена обязаны совпадать с именами папок в `mods\`; несуществующие имена MO2 молча выбрасывает. Мод, которого нет в файле, но папка есть, MO2 добавит с высоким приоритетом, поэтому перечисляйте все моды. |
| Разделитель | Обычная папка `mods\<Имя>_separator`; в файле — строка с этим именем (чаще `-Имя_separator`). Надёжнее создать один разделитель в MO2 и скопировать его формат. |
| `plugins.txt` | «Звёздочный» формат: включённый плагин `*Имя.esp`, выключенный `Имя.esp`. Порядок сверху вниз — по возрастанию приоритета загрузки. Официальные мастера не пишутся и активны принудительно. ANSI, поэтому избегайте не-ASCII в именах плагинов. **Пустым не оставлять** — тогда всё станет неактивным. |
| `loadorder.txt` | Имена плагинов в порядке загрузки, без звёздочек, UTF-8. Правьте согласованно с `plugins.txt`: если `plugins.txt` новее, порядок берётся из него. |
| `meta.ini` мода | INI, секция `[General]`: `modid`, `gameName`, `version`, `installationFile`, `repository=Nexus`. Лучше ставить моды через MO2 и дать ему записать файл самому. `modid` и `fileid` видны в имени архива: `Name-62089-7-4-5-….7z`. |
| `settings.ini` профиля | `LocalSettings`, `LocalSaves`, `AutomaticArchiveInvalidation`. |

ESL-плагины MO2 считает «лёгкими» только если в VFS есть `skse\plugins\skyrimvresl.dll`: мод Skyrim VR ESL Support ставится **до** расстановки ESL.

## 2. Root Builder и запуск (проверено по документации Root Builder)

- Внутри мода всё, что должно лежать рядом с `SkyrimVR.exe`, кладётся в подпапку **`Root`**. Остальное остаётся на верхнем уровне как обычные Data-файлы. **Папку `Data` внутри `Root` класть нельзя** — Root Builder игнорирует такой мод целиком.
- Режим на вкладке Mode: **Copy** (по умолчанию, самый совместимый). Для VR именно он: `sksevr_loader.exe`, Part 2 Engine Fixes и `openvr_api.dll` должны физически лежать в папке игры. Link требует NTFS, USVFS может не работать для exe и dll.
- Автосборка включена по умолчанию: файлы переносятся при запуске любого приложения из MO2 и убираются при закрытии. После аварийного завершения: **Tools → Root Builder → Clear**. После ручного Build всегда делайте Clear. Не нажимайте «unlock» при работающем MO2.
- Запуск игры: в **Executables** добавьте запись с `Binary = <MO2>\mods\<мод SKSEVR>\Root\sksevr_loader.exe`. Root Builder перенаправит запуск в папку игры. Встроенная запись «SKSE» указывает в папку игры и работает только пока файлы развёрнуты. Игру запускать **только** через эту запись, не через Steam и не через `SkyrimVR.exe`. Steam и рантайм OpenXR должны быть запущены.
- Остальные инструменты (xEdit, LOOT, Pandora, DynDOLOD, BethINI) запускаются тоже из MO2.

## 3. Инструменты (фаза 1)

| Что | Как |
|---|---|
| SSEEdit (#164) | Отдельная папка вне Steam и MO2. Для VR переименовать в `TES5VREdit.exe` или запускать с `-tes5vr`. Версия 4.1.5q и новее: 4.1.5f падала на Update.esm в Skyrim VR. |
| LOOT | Skyrim VR поддерживается. Запись в MO2: `Arguments = --game="Skyrim VR"` (плагин MO2 создаёт её сам). Запускать из MO2, затем Apply Sorted Order и закрыть. Skyrim VR ESL Support должен стоять до сортировки. |
| BethINI Pie + плагин для Skyrim VR | Запускать **из MO2** и выбирать «Skyrim VR»: тогда правки попадут в профильные INI. Запущенный вне MO2 изменит файлы в Documents, а профиль останется прежним. После работы проверить, что `sLocalSavePath` и `bUseMyGamesDirectory` на месте. |
| Pandora Behaviour Engine+ | Не в `Data`. Как приложение MO2, `Arguments = -o "<абсолютный путь к mods\Pandora Output>"` (пустой мод «Pandora Output» создайте заранее), для VR добавить `--tesv:"<папка с SkyrimVR.exe>"` **(проверить)**. VR-поддержка вернулась в 4.1.2-beta. Пересобирать после любых анимационных модов. |
| Synthesis | Отдельная папка, нужен .NET SDK. При создании профиля выбрать релиз **Skyrim VR**, запускать из MO2. Результат (`Synthesis.esp`) попадёт в Overwrite — перенести в мод «Synthesis Output». Проверять по описанию каждого патчера, что он поддерживает SkyrimVR. |
| fpsVR или SteamVR Frame Timing | Время кадра CPU и GPU, а не загрузка видеокарты. |

## 4. Мастера игры и USSEP (фаза 1)

Выбор — `MASTERS_PATH` из `SYSTEM_PROMPT.md`.

- **Путь A (есть Skyrim SE/AE).** По гайдам infernalryan «Skyrim Initial Setup (VR)» (v2.2.1) и «Updating Game Masters»: с установленной SE/AE берутся обновлённые мастера и 4 бесплатных CC (Survival Mode, Fishing, Rare Curios, Saints & Seducers), складываются в отдельный мод MO2, который стоит **первым после инструментов**. Затем Strings Fix, затем USSEP 4.3.x. Точный список копируемых файлов агент берёт из гайда, не выдумывает **(проверить)**.
  - «Skyrim VR Strings Fix for Updated SSE Master Files» (#176040, v2.0): нужен, потому что loose-строки VR перекрывают строки из BSA (пропадает текст, не поднимаются отмычки). Проверьте, что в архиве есть строки вашего языка.
  - «Skyrim VR Survival Text Removed» (#177398): при включённом плагине Survival Mode; плагин оставить включённым — это мастер USSEP. «Survival Mode Prompt Removed» (Disable Permanently).
  - «Skyrim VR Fixes for Latest USSEP» (#177650): ESL-мастер сразу после USSEP, при белых деревьях.
  - Порядок в MO2: мод с мастерами → Strings Fix → USSEP.
- **Путь B (SE/AE нет).** USSEP **4.2.5b** (из «Old files» страницы #266) и «SkyrimVR USSEP 4.2.5b Compatibility Patch» (#91475). Подтверждено VR-сборками (Stormcrown VR, Panda's Sovngarde). Несовместим с путём A; 4.2.5b не ставить поверх 4.3.x.
- Чистка мастеров: Quick Auto Clean только для Update, Dawnguard, HearthFires, Dragonborn (Skyrim.esm не чистить), свежий USSEP не чистить. Результат попадёт в Overwrite — перенести в мод «Cleaned Masters». Точный синтаксис QAC сверить с Tome of xEdit **(проверить)**.

## 5. SKSEVR, библиотеки, фиксы (фаза 2)

1. **SKSEVR 2.0.12** (#30457): `sksevr_loader.exe` и `sksevr_1_4_15.dll` — в **Root**, проверить, нет ли в архиве `sksevr_steam_loader.dll`; папка `Data` архива (скрипты) — на верхнем уровне мода, не в Root.
2. **VR Address Library for SKSEVR** (#58101) — обновлять вместе с каждым SKSE-плагином. Файл версии для 1.4.15 лежит в `Data\SKSE\Plugins`. Если плагин не грузится — проверить сначала её и то, что DLL именно VR-сборка.
3. **Engine Fixes VR 7.x** (#62089): это единая сборка SE/AE/VR от alandtse, не старый 1.x. **Part 1** — обычный мод. **Part 2** («Part 2 Engine Fixes VR v1.26/v1.26a») — целиком в **Root**; внутри `tbb12.dll`, `tbbmalloc.dll` и прелоадер. Старые `tbb.dll` и `tbbmalloc.dll` из прежних установок **удалить**. Настройки — `Data\SKSE\Plugins\EngineFixes.toml` (создаётся при первом запуске игры; правьте после выхода): секция `[Patches]`, ключ **`bMaxStdIO = true`** (по умолчанию уже true, число задавать не нужно); он нужен Skyrim VR ESL Support, которому достаточно лимита не ниже 2048 открытых файлов. Старый отдельный ObjectLOD/Shadow Map fix не ставить: внутри с 7.4.9.
4. **Skyrim VR ESL Support** (#106712, 1.3.2): `skyrimvresl.dll`, только с официальным SKSEVR 2.0.12, нужен Engine Fixes VR. Файл «PapyrusUtil ESL Patch» ставить, если есть PapyrusUtil. Конфиг `SkyrimVRESL.ini` создаётся сам. Если в `SkyrimVRESL.log` предупреждение «Required Engine Fixes VR MaxStdio patch not detected» — проверить `bMaxStdIO`. Ставится до расстановки ESL и до DynDOLOD.
5. **Crash Logger SSE AE VR** (+PDB) — логи вылетов.
6. «Основной мод + VR-DLL поверх»: powerofthree's Papyrus Extender → Papyrus Extender VR; po3 Tweaks → po3 Tweaks VR; CDF → CDF VR; Light Placer → Light Placer VR. VR-файлы ставятся второй раз поверх и перезаписывают.

Проверка запуска: `Documents\My Games\Skyrim VR\SKSE\sksevr.log` (имя подтверждено косвенно; каталог логов плагинов определяется папкой `My Games\Skyrim VR`). Загруженный плагин — строка «loaded correctly»; неудача — «disabled, fatal error occurred while loading plugin», «reported as incompatible during query», «is incompatible with current runtime version», «no version data» или «does not appear to be an SKSE plugin» (формулировки искать по имени dll). Вылеты — `crash-*.log` Crash Logger в той же папке.

## 6. Шейдеры и VR-ядро (фаза 3)

- **Open Shaders** (или CSX — `SHADERS`) ставится вместо Community Shaders, не оба. Нужны Engine Fixes VR и VR Address Library. Настройки: DLAA при запасе GPU, иначе DLSS Quality/Balanced; фовеальный рендеринг включить; генерацию кадров не использовать. Тяжёлые функции — по одной с замером: Wetness, SSGI/AO, Screen Space Shadows, Terrain Blending.
- VRIK, HIGGS, PLANCK, затем Physical Collision VR, True Wield VR, Immersive Weapon Penetration VR (цепочки зависимостей — в манифесте). Pseudo Physical Weapon Collision вместе с Physical Collision VR не ставить.

## 7. Интерфейс, звук, свет, погода, ландшафт (фазы 4–5)

SkyUI VR, MCM Helper, затем остальное. Sound Record Distributor — для звуковых модов. **Lux** — в установщике без разделённых мешей; меши `Lux_*` оставить. **CS Light** — не включать вместе «ENB lights for effect shaders» и «Magic FX lights»; при Embers XD включить опцию под него. Azurite Weathers III + MCM + HDR; Volumetric Mists не ставить. Одна вода, одна трава, один набор следов (группы «одно из» — `CONFLICTS.md`).

## 8. Анимации (фаза 6)

OAR-пакеты NPC; XPMSSE + VR-фикс скелета первого лица (после XPMSSE). Генератор поведений только один — Pandora, Nemesis не ставить. Pandora запускается после всех анимационных модов, вывод — в отдельный мод ниже модов-источников.

## 9. Геймплей, хайтек, ИИ-NPC (фазы 7–9)

Бой и геймплей — SimonRim вместе с Poached Bugs VR (Simonrim Choice Config). Хайтек-новинки — **по одному**, после каждого запуск и проверка `sksevr.log` по полю `verify`; метка `try` — только с разрешения пользователя. ИИ-NPC — один из SkyrimNet / Mantella / CHIM; для SkyrimNet в VR нужны Skyrim VR ESL Support, Skyrim VR Refocused, MFG Fix NG, po3 Tweaks (SE и VR).

## 10. VR-рантайм и OpenComposite

- **OpenComposite Unleashed** (#171182, 5.x): `openvr_api.dll` — в **Root**, SKSE-плагин `OpenCompositeInput.dll` — в `Data\SKSE\Plugins`, рядом программа-конфигуратор; остальное по структуре архива. Оригинальный `openvr_api.dll` Root Builder сохраняет (backup) и возвращает при Clear. INI и ключи Unleashed читать в README мода **(проверить)**. Настройки при обновлении сохранять. Не ставить вместе со старым OpenComposite Fixes Custom Build. Чтобы вернуться на SteamVR, мало отключить мод: удалить папку `shadercache` в папке игры.
- Рантайм OpenXR выбирается вне MO2: SteamVR — «Set SteamVR as OpenXR runtime» в настройках SteamVR; VDXR — Virtual Desktop Streamer → Options → OpenXR Runtime = VDXR (в оверлее Virtual Desktop поле Runtime покажет VDXR); Oculus — «Set Oculus as active OpenXR runtime» в приложении Oculus (формулировки двух последних пунктов **проверить**). Оверлеи SteamVR при OpenComposite пропадают.

## 11. Финальная генерация (после текстур)

Строго по порядку, каждый шаг пишет в **отдельный пустой мод** внизу списка (создать заранее): «Pandora Output», «Synthesis Output», «Grass Cache», «xLODGen Output», «TexGen Output», «DynDOLOD Output».

1. Все моды и текстуры установлены; LOOT; конфликты в xEdit.
2. PGPatcher (ParallaxGen) — если стоят PBR или parallax-текстуры.
3. Synthesis.
4. **Прекэш травы NGIO-NG** (#42161, 1.6.x; нужны Grass Cache Helper NG #101095, VR Address Library): в `Data\SKSE\Plugins\GrassControl.ini` (создаётся при первом запуске) `Use-grass-cache=true` и `Only-load-from-cache=true` (имена ключей сверить со своим файлом). Плагин «Grass Generation MO2 Plugin» (файлы на странице NGIO) — в `<MO2>\plugins`; по README в его скрипте поправить строки `grassPluginPath = "SKSE/Plugins/"` и `grassPlugin = "*NGIO-NG.dll"` **(проверить по версии плагина)**. Перед прекэшем **Tools → Root Builder → Build**, чтобы `sksevr_loader.exe` лежал в папке игры, после — Clear. `PrecacheGrass.txt` создаётся в корне игры (рядом с `SkyrimVR.exe`) и служит маркером прогресса; добавьте его в исключения Root Builder. **Tools → Plugins → Precache Grass** перезапускает игру до сообщения «Grass Caching complete»; падения при этом ожидаемы. Файлы `.cgid` из `Data\Grass` в Overwrite перенести в мод «Grass Cache». При смене травы, ландшафта, плагинов или `iMinGrassSize` кэш делается заново. Файл `PrecacheGrass.txt` при обычной игре должен отсутствовать.
5. **xLODGen**: `TES5VRLODGenx64.exe` или `-tes5vr`; вывод — `-o:"путь\"` (двоеточие обязательно) или поле Output в окне, в мод «xLODGen Output». Ресурс «SSE Terrain Tamriel» (#54680) включать только на время генерации. Известная проблема VR: «Fatal: Could not find ini» при запуске из MO2 — убедитесь, что `skyrimvr.ini` и `skyrimprefs.ini` есть в профиле. Нужен xEdit-совместимый режим VR **(проверить на стороне xLODGen)**.
6. **TexGen**, затем **DynDOLOD 3** (Resources SE 3, DynDOLOD DLL NG #97720): оба с `-tes5vr`, выход в моды «TexGen Output» и «DynDOLOD Output». DLL NG общая для SE/AE/VR, старую DLL VR не ставить. Распаковывать вне mods и вне игры. Имена exe (`TexGenx64.exe`, `DynDOLODx64.exe`) **проверить**. Руководство по VR — `docs\DynDOLOD_Manual_TES5VR.html` в архиве. Skyrim VR ESL Support должен быть установлен до запуска.
7. Тестовый прогон: Вайтран, Рифтен, лес у Ривервуда; время кадра и `crash-*.log`.

## Русский язык

Сборки Wabbajack требуют английскую игру. Для русской игры понадобятся: русские строки в Strings Fix (проверить, заявлены ли они в моде), переводы ESP-модов (вкладка Translations на Nexus, xTranslator), шрифты с кириллицей для SkyUI VR, Scaleform Translation++ VR и Dynamic String Distributor (уже в ядре). Готового русификатора для VR не найдено. Список — во второй подборке «Skyrim VR Other Mods 2026», раздел «Русификация».

## Что агенту проверить на актуальных страницах

1. Список файлов, которые копируются для пути A (гайд infernalryan), и наличие `sksevr_steam_loader.dll` в архиве SKSEVR.
2. Имя INI и ключи OpenComposite Unleashed.
3. Имена исполняемых файлов DynDOLOD, TexGen, xLODGen и синтаксис Quick Auto Clean.
4. Аргумент `--tesv` для Pandora в VR.
5. Названия опций установщиков там, где в карточке стоит «неизвестно — общие правила».
6. Точные строки меню активации рантайма Oculus и SteamVR.
