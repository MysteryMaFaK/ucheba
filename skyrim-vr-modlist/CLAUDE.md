# Skyrim VR Core 2026 — пакет установки

Папка внутри приватного репозитория «Учёба», к учёбе отношения не имеет: это сборка модов Skyrim VR для владельца репозитория.

- Порядок чтения: **`NEW_CHAT_PROMPT.md`** → **`CONTEXT_FOR_NEW_CHAT.md`** → **`HANDOFF.md`** → `FILES.md`. В `HANDOFF.md` — состояние и команды продолжения.
- Установка модов в MO2: **`SYSTEM_PROMPT.md`** (или навык `/skyrim-vr-install`), главный источник — `manifest.yaml`; порядок, группы «одно из» и запреты — `CONFLICTS.md` (при расхождении побеждает он).
- Играет в **Skyrim VR 1.4.15**, не в SE/AE. DLL только для SE в VR не работает — проверяй VR-файл.
- Общение на русском. Не входи в аккаунт Nexus и не вводи пароли: скачивает владелец.
- `manifest.yaml`, `MODLIST.md`, `CONFLICTS.md`, `links/`, `OTHER_MODS.md`, `site/*.html` **генерируются** скриптами: правки вносить в исходники (см. `HANDOFF.md`, «Где править»), иначе пересборка их сотрёт.
- Не коммить, не пушь и не публикуй страницы без просьбы владельца.
- Репозиторий приватный, публичным не делать. `data/rep/` скачивается `python tools/fetch_reports.py` и в git не попадает.
