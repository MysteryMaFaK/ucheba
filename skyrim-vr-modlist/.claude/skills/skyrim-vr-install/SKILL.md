# Установка Skyrim VR Core 2026

1. Прочитай `SYSTEM_PROMPT.md` в корне этого проекта целиком и работай строго по нему.
2. Источник правды — `manifest.yaml`, затем `CONFLICTS.md`, затем `INSTALL_GUIDE.md`. `MODLIST.md` — то же в читаемом виде, `links/` — ссылки по фазам.
3. Начни с блока «Конфигурация» из `SYSTEM_PROMPT.md`: спроси пользователя недостающие значения одним сообщением и запиши их в `install_log.md` в папке MO2.
4. Если `install_log.md` уже есть — продолжай с последней незавершённой фазы, не переустанавливай готовое.
5. Аргументы вызова, если есть: `фаза N` — начать с фазы N; `проверка` — только сверить установленное с манифестом и отчитаться о расхождениях; `мод <id>` — поставить или починить один мод.
