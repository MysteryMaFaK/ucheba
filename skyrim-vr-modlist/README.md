# Skyrim VR Core 2026 — пакет для установки через Claude

Технический пакет, по которому Claude на вашем компьютере ставит сборку в Mod Organizer 2. В пакете: какие файлы скачивать, что выбирать в установщиках, требования, патчи, конфликты, порядок и проверки.
Текстуры сюда не входят: это следующий этап.

> Манифест ядра готов: 287 модов, у всех карточки установки (у 12 требований, добавленных проверкой согласованности, карточка короткая — файл и выборы агент читает на странице мода). Вторая подборка «Other Mods 2026» пока только как список, без файлов установки.

Читаемая версия со списком и отметками — страница [Skyrim VR Core 2026](https://claude.ai/artifact/CtFycL6Py2fC2TDY7NZgCa).

## Как запустить

**Вариант 1 — Claude Code в десктопном приложении (вкладка Code).** Лучший вариант: у агента есть доступ к файлам, он сам распакует архивы и поправит файлы MO2.

1. Скопируйте папку `skyrim-vr-modlist` в удобное место, например рядом с папкой MO2.
2. Откройте эту папку как проект во вкладке Code.
3. Напишите `/skyrim-vr-install` — агент спросит пути и выборы и начнёт с фазы 0.
4. Дайте агенту доступ к папкам игры и MO2, когда он попросит.

**Вариант 2 — обычный чат, проект Claude.** У чата нет доступа к файлам, агент ведёт вас по шагам, а вы присылаете скриншоты и логи.

1. Создайте проект, в инструкции проекта вставьте весь текст `SYSTEM_PROMPT.md`.
2. В знания проекта загрузите `manifest.yaml`, `CONFLICTS.md`, `INSTALL_GUIDE.md`, `MODLIST.md`.
3. Напишите в чате: «Начинаем установку, фаза 0».

**Вариант 3 — разово.** Перетащите все файлы в чат и напишите: «Работай по SYSTEM_PROMPT.md».

## Что агент не делает

- Не входит в Nexus и не вводит пароли. Скачиваете вы — кнопкой «Mod Manager Download» или вручную в папку `downloads` MO2.
- Ничего не удаляет без вашего «да».
- Моды с меткой `try` ставит только по одному и с вашего разрешения.

## Метки

`core` — обязательно · `rec` — рекомендую · `opt` — по желанию · `alt` — вариант внутри группы «одно из» · `try` — VR заявлен, но не обкатан: ставить по одному и проверять.

Данные сверены 08.10.2026 с составом 27 популярных сборок Wabbajack (9 VR и 18 плоских next-gen) и с исходниками модов на GitHub. Версии со временем меняются: если страница мода расходится с манифестом, агент вам об этом скажет.
